### 発展

- やったこと：
  - 質問を4種類（短い事実「日本の首都は？」／説明「LoRAとは？」／コード「リストの重複を取り除く関数」／講座固有「宿題の3レベル」）にして、gemini-3.5-flash-lite・3.6-flash・3.8-flashで2回ずつ実行した（計24回）
  - ストリーミングで受け取り、「最初の文字が来るまで」と「全部そろうまで」の時間を分けて測った。トークンは入力・出力・thinkingに分けて記録した
  - 自分のキーのプロジェクトは課金ありだったので、出力は2048トークンまでにして、概算の料金を出しながら回した（24回で約13円）
  - スクリプト：`lectures/01/advanced_runs.py`、結果：`lectures/01/advanced_results.md`
- 結果（2回の平均くらい。秒は「最初の文字まで / 全体」）：

| 質問 | 3.5-flash-lite | 3.6-flash | 3.8-flash |
|---|---|---|---|
| 短い事実 | 1.0 / 1.0秒、thinking 0 | 2.5 / 2.5秒、thinking 約150 | 2.0 / 2.0秒、thinking 約30 |
| 説明 | 0.8 / 2.8秒、thinking 0 | 7 / 12秒、thinking 約970 | 11 / 19秒、thinking 約1060 |
| コード | 0.8 / 2.2秒、thinking 0 | 6.7 / 10秒、thinking 約980 | 8.2 / 12秒、thinking 約900 |
| 講座固有 | 0.9 / 2.5秒、thinking 0 | 9 / 14秒、thinking 約1250 | 11 / 18秒、thinking 約820 |

  - liteはthinkingが0で、最初の文字まで1秒以内。3.6/3.8は答える前に考えていて、最初の文字まで7〜13秒かかる。全体の時間の半分以上が、この「考える時間」だった
  - thinkingのトークンは出力と同じ値段なので、同じくらいの長さの答えでも、3.6/3.8はliteの約4〜5倍の料金になった（説明の質問で lite 約0.25円、3.8 約1.05円）
  - 短い事実の質問だと、3.6-flashは3.8-flashより多く考えていた（約150と約30）。質問が簡単でも、モデルによっては考える量が減らない
  - 説明の質問の1回目だけ、liteが52秒、3.6が84秒かかった（2回目は3秒と12秒）。トークン数はほぼ同じなので、サーバー側の待ち時間だと思う。1回だけ測ると外れ値を拾ってしまう
  - 講座固有の質問は、thinkingを1000トークン以上使っても、やはり講座の正しい3レベルは答えられなかった。考える量を増やしても、知らないことは分からないままだった
- レート制限との関係：
  - スライドの無料枠は、3.5-flash-liteが「毎分15・1日500」、3.8-flashが「毎分5・1日10〜20前後」
  - 3.8-flashは1回に15〜20秒かかるので、1本ずつ順番に投げるなら毎分5回にはほぼ届かない。先に効くのは1日の上限のほうで、今回の基礎（3.8を6回）＋発展（3.8を8回）だけで、1日の枠をほぼ使い切る計算になる
  - liteは1回が1〜3秒なので、待ち時間を入れずに連続で投げると、毎分15回をすぐ超える。liteで繰り返し比べるときは、毎分の上限のほうに注意が要る
  - 比べる実験で回数を稼ぐならlite、数問だけ質を見たいときに3.8、と使い分けるのがよさそう。thinkingのぶん料金も時間もかかるので、課金ありの場合はなおさら
  - 今回は課金ありのプロジェクトだったので、無料枠の429エラーは実際には出せなかった。無料のキーでliteを待ちなしで回して、何回目で429が返るかは次に試したい
