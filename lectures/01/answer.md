## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  「AIE2026はAIエンジニア育成講座のようなものだと思われる」と前置きして、レベル1＝基礎（サンプルを動かす・穴埋め）、レベル2＝応用、レベル3＝発展という一般的な難易度の分け方を説明していた。「正確にはシラバスを確認してください」とも書いていた。
- 用語集の正しい意味と比べて気づいたこと：
  正しくは「基礎（講義内容の確認）／実装（自分でコードを書く）／発展（調査や試行）」で、どれか1つやれば完了。モデルは段階の数と「基礎」は当たっていたが、「難易度順に積み上げる」「レベル1が必須」のような、講座にない前提を自信ありげに付け足していた。講座のことは知らないのに、それっぽい答えを作ってしまうのが分かった。
- 表示できたトークン数（入力 / 出力）：21 / 554（gemini-3.5-flash-lite、宿題の3レベルの質問）

## 宿題

- 取り組んだレベル：基礎
- 使ったモデル：gemini-3.5-flash-lite、gemini-3.8-flash（temperatureは既定のまま）
- やったこと：
  - 「LoRAとは何ですか？」（一般的な用語）と「AIE2026の講座の宿題にある「3レベル」とは何ですか？」（講座に固有のこと）の2問を、2つのモデルで3回ずつ実行した（計12回）
  - `lectures/01/basic_runs.py` で回して、回答・時間・トークン数を `lectures/01/basic_results.md` に保存した
- 結果：

| 質問 | モデル | 時間（秒） | 出力トークン |
|---|---|---|---|
| LoRA | 3.5-flash-lite | 3.3 / 2.9 / 3.5 | 661 / 473 / 649 |
| LoRA | 3.8-flash | 16.7 / 18.8 / 18.8 | 706 / 634 / 959 |
| 3レベル | 3.5-flash-lite | 3.2 / 2.9 / 2.9 | 611 / 541 / 552 |
| 3レベル | 3.8-flash | 19.2 / 19.5 / 15.8 | 668 / 694 / 594 |

  - LoRA：どちらのモデルも内容はおおむね正しく、「少ないパラメータだけ学習する」「ファイルが小さい」などの要点は毎回同じ。ただ、見出しの立て方や例えは毎回変わった。3.8-flashの2回目は、通信規格の「LoRa」の補足まで付けていた
  - 3レベル：6回とも「分からない」とは言わず、一般的な難易度別の3段階を説明した。中身は回ごとに少しずつ違い、3.8-flashは「AIツールの活用度の3レベルかもしれない」という別パターンまで出していた
  - 3.8-flashは1回あたり15〜20秒で、lite（約3秒）の5倍くらい遅い。出力も少し長め
- 気づき・疑問：
  - 同じ質問・同じモデルでも、毎回答え方が変わる。temperatureを下げれば揃うのかは今回試していない
  - 上位モデルでも、知らないことには「知らない」と言わずにもっともらしく答える。モデルを強くするより、講座の資料を渡す仕組み（第3回の用語集検索）が要りそう
  - 最初に作ったAPIキーのプロジェクトが前払いの課金設定になっていて、残高0で402エラーになった。課金なしの新しいプロジェクトでキーを作り直したら動いた
